# 💰 Simpan — Savings Goal Planner

**Simpan** is a simple, beautiful savings goal planner that helps you set a target, track every ringgit you save, and see at a glance how close you are to reaching it.

The name comes from the Malay word *simpan* ("to save/keep") — fitting for an app with Malaysia-flavoured sample data, RM currency, and entries like ASB dividends and Touch 'n Go cashback.

---

## ✨ Features

- **Goal panel** — shows your savings target (RM 10,000), deadline (31 Dec 2026), current total saved, and an animated progress bar.
- **Goal check** — every time the total changes, the app instantly recalculates how much is left to reach the goal, with a celebration state when you cross the finish line.
- **Add money panel** — enter an amount with an optional note, or use quick-add buttons (+50 / +100 / +250 / +500). Invalid amounts are rejected with a friendly message.
- **Savings entries** — starts with Malaysia-specific sample entries (salary savings, Shopee side hustle, mamak night skip fund, and more), each with its own colored icon tile.
- **Delete entries** — remove any entry with one click; totals and progress update immediately.
- **Polished UI** — dark theme with mint and violet glows, glassy cards, shimmer progress bar, toast notifications, and full mobile responsiveness.

## 🖼️ Panels

| Panel | What it does |
|---|---|
| Goal | Displays target, deadline, total saved, progress bar, and remaining amount |
| Add Money | Lets you add an amount (with optional note) to your savings right now |
| Savings Entries | Lists all savings entries, newest first, with delete buttons |

## 🚀 Getting Started

No build tools, dependencies, or server required — it's a single HTML file.

1. Open `index.html` in any modern browser.
2. That's it. Start adding savings!

## 🛠️ Tech Stack

- **HTML** — single-file structure
- **CSS** — custom dark theme, animations, responsive grid
- **Vanilla JavaScript** — state management and DOM rendering, zero frameworks
